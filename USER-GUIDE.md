# DC Coms User Guide

Open the HTTPS address supplied by your administrator and sign in with your DC Coms username and password. Matrix identities look like `@username:server.example`.

DC Coms provides private channels and direct messages. Depending on permissions, users can send messages, reply, edit, delete, react, pin, search, rename channels, and update channel topics.

Community V1 includes standard Unicode reactions and emoji. Private/custom character packs are not included.

Encrypted rooms support encrypted attachments. Images and files can also be pasted from the clipboard where supported.

Type `@` while composing to select a user. Mentions are highlighted. Drafts are preserved per user and room. Matrix typing indicators show active composition.

Browser notifications require browser permission.

The account/security area can be used to review Matrix sessions and remove untrusted device/browser sessions.

Authenticated users can change their password. Community V1 requires replacement passwords between 12 and 512 characters.

For a forgotten password, contact an administrator. Administrators can issue a short-lived reset/setup code without choosing or seeing the replacement password.

Log out when using a shared or untrusted system.
